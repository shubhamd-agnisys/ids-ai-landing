The synchronization problem, solved at the source

Design RTL, UVM testbenches, firmware headers and documentation are usually written by different teams from different copies of the spec: Word files, spreadsheets, PDFs. When the spec changes, the copies drift apart, and the mismatch surfaces late in verification or integration, when fixes are most expensive.

IDS-CF™ (IDesignSpec Collaboration Framework) puts all teams on a single Golden Specification. Author it once, validate it with AI, and generate RTL, verification collateral, software headers and documentation from it, so every output stays consistent with the spec.

On top of the platform, IDS-AI™ adds a multi-agent AI layer that checks, extracts, generates and debugs from the Golden Specification, and IDS-MCP™ lets your own AI assistant drive the IDS toolchain in plain language.

Golden Specification–driven chip sign-off with agentic AI

IDS-AI is a multi-agent layer that runs on the IDS-CF platform. Every agent works from the same Golden Specification, so the output of one agent is the trusted input of the next.

See IDS-AI

See it live in a demo →

SpecCheck Agent
Checks the spec for correctness, completeness, consistency and AI-readiness before anything is generated, so errors are caught at the cheapest point to fix them.
Extract Agent
Converts unstructured PDF, text, HTML and Markdown into structured, machine-readable design information that becomes part of the Golden Specification.
RTL Generator Agent
Generates Verilog, SystemVerilog and VHDL, and handles SoC assembly and integration from connectivity information.
Verification Agent
Creates the entire verification environment (monitors, drivers and sequences) along with the sequences to drive coverage toward 100%. Custom sequences are captured through GUI templates.
SV Assertion Agent
Generates SystemVerilog Assertions and the formal verification environment for assertion-based testing.
Summary / Debug Agent
Summarizes design specifications, identifies errors and inconsistencies, and helps debug issues for faster SoC development.

Ask your AI assistant. Run the IDS toolchain.

IDS-MCP is a pair of self-contained server binaries that link your AI programming assistant directly to the IDesignSpec toolchain. Supported assistants include Claude Desktop, Claude Code, Cursor, Cline, Open WebUI and custom agent platforms.

  • ids-mcp-suite

    Generation, verification and integration

    Choose this to build

    • Validate register specs (check_spec)
    • Scaffold and simulate ARV-Sim (UVM) environments
    • Scaffold and run ARV-Formal assertions
    • Run and validate IDS-Integrate SoC connectivity specs
    • Requires idsbatch and an active Agnisys license

    Offline knowledge engine and flag search

    Choose this to learn and look up

    • Instant, deterministic flag lookup and syntax help for idsbatch
    • Semantic search across hundreds of embedded Agnisys guides (IDS-Batch, IDS-Verify, IDS-Validate, IDS-Integrate)
    • Answers architecture, configuration and syntax questions offline
    • Standalone: no idsbatch install, no license
