The synchronization problem, solved at the source

Modern semiconductor development requires hardware, software, firmware, verification, validation, and system teams to collaborate on increasingly complex IP and SoC specifications. Maintaining these specifications across multiple documents, spreadsheets, and formats often results in inconsistencies, duplicated effort, communication gaps, and costly design iterations.

IDS-CF™ (IDesignSpec Collaboration Framework) provides a unified, AI-powered platform that enables all engineering teams to collaborate using a single golden specification throughout the IP and SoC development lifecycle.

With an intuitive interface, AI-assisted validation, project management, real-time collaboration, native VS Code integration, and automated output generation, IDS-CF eliminates manual synchronization between teams while ensuring every generated output collateral remains consistent with the specification.

Questions teams ask first

What is a golden specification?

One machine-readable spec that every team works from. IDS-CF generates all outputs from it, so they stay in sync.

Do we have to give up Excel or Word?

No. Import from IDS-Excel, IDS-Word, YAML, IP-XACT, SystemRDL or CSV. Keep working in the Spreadsheet view if your team likes tables.

Which outputs can IDS-CF generate?

Design (Verilog, VHDL, SV, SystemC), verification (UVM RAL, sequences, formal, testbench), software (C/C++ headers, sequence API, tests), documentation (HTML, PDF, PRM, Word, Markdown, JSON) and standards (IP-XACT, SystemRDL).

Can IDS-CF capture programming sequences?

Yes. The Sequence view captures write, if, for, while and wait steps and generates collateral from them.

What does the AI do?

It suggests properties and values while you write the spec, and checks the spec for completeness, consistency and correctness.

Which platforms are supported?

Windows, Linux and macOS.
